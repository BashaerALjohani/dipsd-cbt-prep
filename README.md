# DIPSD CBT Prep

A bilingual (English / Arabic) study site for the DIPSD mock CBT, covering Units 18–24, 26 and 27.

- Interactive lessons: warm-up, learn, apply, exit ticket
- 65 hands-on activities (sort, order, fill the blank, scenarios)
- Narrated lesson clips, keywords, four levels, code walkthroughs
- Flashcards, matching game, quizzes, speed round, timed mock exam
- 14-day plan, focus timer, XP, ranks and badges
- Pink and magic designs

Open `index.html` in a browser, or use the GitHub Pages link. Progress is saved in the browser on each device.

## GA Workshop
A separate page that guides each graded assignment (Units 18–28) task by task: what is required, what it means, steps, screenshots to collect, and what an A needs. You do the work yourself.
